Roll

Anything you can type rolls in place. Click the card to advance to the next value, or edit the list below to supply your own. A comma or Enter starts a new value.

Values
Comma or Enter splits at the caret. Commas are drawn, never typed. Backspace at the start of a value joins it to the one before.

Alignment

Which edge the value holds as it gets wider or narrower. Dynamic keeps the value moving across the card, so you can watch a roll land while the element itself travels.

Trend

Which way the glyphs travel. Auto follows the value, counting up or down with it. Up and down set the direction regardless of the value.

Bounce

How far each character overshoots as it lands. Zero settles flat. The default is 0.20, and the bouncy preset is 0.30.

Duration

How long the roll takes, end to end. Drag the track, or focus it and press the arrow keys.

In a sentence

A value that updates inside ordinary text. The words on either side make room as it grows and close up as it shrinks.

Light has traveled km since this minute began.

Wrapped

When the value changes width, the words after it move between lines at the value's own duration, and the paragraph keeps the height it had.
