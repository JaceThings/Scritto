Docs

How to put a rolling value on the page. The playground is the easier way to feel the motion; this is the short version of what you install and call.

Install

npm install @scritto/core for the element itself. React, Vue, Svelte, and Solid each have a package — @scritto/react and so on — and each one brings the core with it.

The element

Drop <scritto-text> on the page, then set .value or call update(next). Letters that stay, stay. The rest roll.

In a sentence

Wrap the line in <scritto-flow> so the words beside the value slide and wrap when it changes width.

Options

transition: { duration, easing }, trend, bounce, and respectMotionPreference. Try them on the playground before wiring them up.
