Scritto is a JavaScript library that animates text in place. Give an element a new value and only the characters that changed move: each one rolls from the old character to the new one while the rest hold their position. It works on numbers, words, and emoji, with bindings for React, Vue, Svelte, and Solid, and a core that runs without a framework.
