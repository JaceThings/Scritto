Picking a value editor

Six ways to edit the list, all live. Every card behaves the same underneath: the presets load a starting set, the Values editor is always there to change it, and the pills follow what you type — the moment a list stops matching a preset it reads as Custom. Click a card to roll through its values.

Quieter ones

The six above carry a lot of furniture for what is a short list of short strings. These six show nothing at rest but the values themselves — no counters, no hints, no buttons on every item — and reuse the same row the rest of the card already uses. What has to exist is a keystroke, or waits for your cursor.
