Resize

A value animating its width inside a container that shrink-wraps it. The container should ride the transition frame by frame — never clip, never lag, never keep slack. Each card measures exactly that on every frame of every roll: the host's layout box inside the container's content box, and the container hugging once settled. Click any card to step it. The last card is the failure for comparison: a fixed-width box that cannot follow.
