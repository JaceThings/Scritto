# @scritto/react

React wrapper for [`@scritto/core`](https://www.npmjs.com/package/@scritto/core).

## Install

```sh
npm install @scritto/react
```

## Usage

```tsx
import Scritto from "@scritto/react";

<Scritto value="1,000" />
```

See the [root README](https://github.com/JaceThings/Scritto).
