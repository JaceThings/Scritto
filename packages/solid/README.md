# @scritto/solid

Solid wrapper for [`@scritto/core`](https://www.npmjs.com/package/@scritto/core).

## Install

```sh
npm install @scritto/solid
```

## Usage

```tsx
import Scritto from "@scritto/solid";

<Scritto value="1,000" />
```

See the [root README](https://github.com/JaceThings/Scritto).
