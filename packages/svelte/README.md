# @scritto/svelte

Svelte wrapper for [`@scritto/core`](https://www.npmjs.com/package/@scritto/core).

## Install

```sh
npm install @scritto/svelte
```

## Usage

```svelte
<script>
  import Scritto from "@scritto/svelte";
</script>

<Scritto value="1,000" />
```

See the [root README](https://github.com/JaceThings/Scritto).
