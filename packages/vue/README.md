# @scritto/vue

Vue wrapper for [`@scritto/core`](https://www.npmjs.com/package/@scritto/core).

## Install

```sh
npm install @scritto/vue
```

## Usage

```vue
<script setup>
import Scritto from "@scritto/vue";
</script>

<template>
  <Scritto value="1,000" />
</template>
```

See the [root README](https://github.com/JaceThings/Scritto).
